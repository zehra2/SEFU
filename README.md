# SEFU - Smart Hospital Management System

Smart Hospital Management Information System (HMIS) with custom clinical modules and Kenya Digital Health Agency (DHA) certification compliance.

## Included Modules & Features
- **Physiotherapy Clinical Module** (`/admin/physiotherapy`)
- **Pediatric Clinical Module** (`/admin/pediatric`)
- **Gynaecology Clinical Module** (`/admin/gynaecology`)
- **Strict Password Policy & Storage Controls (DHA-011)** (Bcrypt hashing, 8+ character complexity enforcement)
- **Kenya DHA Compliance Documentation** (`DHA_HMIS_Developer_Compliance_Tracker.md`)
- **Full Database Export**: `sfu_database.sql`
